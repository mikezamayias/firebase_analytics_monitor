# Famon Brand Assets

Generated for the Aegean package identity direction.

## Direction

- Layout: maintainer package card, matching the approved Option A structure.
- Mark: font-rendered `f›` set in `JetBrainsMono-ExtraBold`.
- Typography: JetBrains Mono for terminal/package metadata; native system sans for package display/copy legibility.
- Palette:
  - `argent-soft` `#faf6ec`
  - `aegean-deep` `#15445e`
  - `santorini-cyan` `#0892d0`
  - `ink-soft` `#4a453d`
  - `ink-faint` `#8a8478`
  - `rule-soft` `#ddd4ba`

## Pub.dev Screenshots

Pub.dev screenshots should show product behavior, not branding. The package
metadata uses `assets/pub/famon_cli_demo.gif`, copied from the tracked demo GIF
and kept under pub.dev's 4 MB screenshot limit.

## Constraints

- No image-model generation.
- No mascot, flag, decorative regional symbol, or glossy gradient treatment.
- No source code changes are required for these assets.
